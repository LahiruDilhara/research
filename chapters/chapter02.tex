\chapter{Literature Review}

\section{Chapter Overview}
\label{sec:lit_chapter_overview}
The rapid evolution of mobile computing, augmented reality (AR), virtual reality (VR), and ubiquitous edge systems has fundamentally reshaped user expectations for Human-Computer Interaction (HCI). For over a century, text input and spatial command execution have relied almost exclusively on mechanical QWERTY key switches and capacitive touchscreens. Although electromechanical hardware provides unambiguous physical tactile feedback and high typing entry speeds for trained typists, its static physical form factor imposes severe operational constraints \cite{ReviewVirtualKeyboard2020, Lee2022Virtual}. Physical keyboards occupy static desktop real estate, lack the ability to dynamically adapt key arrangements for domain-specific software tasks (such as audio editing, industrial CAD design, digital painting, or video production), present hygienic pathogen transmission vectors in sterile medical cleanrooms and public kiosks, and are vulnerable to liquid damage and mechanical key switch wear \cite{ReviewVirtualKeyboard2020}.

To transcend these physical constraints, computer vision researchers have explored virtual input interfaces that transform ordinary physical surfaces or open air into interactive input zones using standard camera sensors \cite{Zhang2001Visual, Srivastava2012RealTime, Khare2019QWERTY, Maman2023TypeNet}. Monocular vision-based virtual keyboards offer a compelling paradigm: by monitoring a flat physical plane (such as a paper sheet or wooden desk) with a single commodity RGB camera, users can interact with virtual key elements without requiring physical switches or dedicated input hardware.

However, realizing a reliable, low-latency, and customizable virtual keyboard operating on monocular RGB video feeds presents major challenges in computer vision, kinematic motion modeling, and sequential deep learning. Core technical obstacles include:
\begin{enumerate}
    \item \textbf{Inferring Z-Axis Touch Surface Impact without Depth Hardware:} Standard monocular RGB cameras lack explicit depth information. Inferring the exact instant a fingertip impacts a flat surface—distinguishing deliberate key contact from hovering movements—without expensive Time-of-Flight (ToF) sensors or active laser projection units remains a fundamental visual perception problem \cite{Thomas2013Camera, Posner2012Single, Lee2019Virtual, Toshpulatov2024RealTime}.
    \item \textbf{Spatial Scale Variance and Kinematic Signal Integrity:} Skeletal hand landmark detectors output raw pixel coordinates that vary drastically with hand size, camera distance, and user position \cite{Zhang2020MediaPipe, Doan2022Efficient}. Normalizing spatial features directly from keypoint trajectories while avoiding temporal low-pass smoothing (which damps rapid kinetic contact spikes and introduces phase delay) is critical for real-time contact detection \cite{Kumar2026Hybrid}.
    \item \textbf{Dynamic Perspective Tilt and Camera-to-Surface Alignment:} When physical paper layouts or commodity RGB cameras shift, perspective distortion corrupts static 2D coordinate mappings. Real-time planar fiducial tracking and homography matrix transformation ($H \in \mathbb{R}^{3 \times 3}$) are required to maintain continuous spatial alignment \cite{Wang2016AprilTag2, Kallwies2020Determining, Pirchheim2011Homography, Herdiansyah2024Implementation}.
    \item \textbf{Integrated Layout Customization and System Action Mapping:} Existing virtual typing systems enforce static QWERTY layouts, lacking software design tools that generate printable paper templates embedded with visual fiducial anchors while synchronizing XML key schemas with custom keystrokes or shell commands \cite{ReviewVirtualKeyboard2020}.
\end{enumerate}

This chapter presents a comprehensive, critically evaluated review of the literature surrounding vision-based virtual input systems, planar fiducial tracking, skeletal hand joint estimation, scale normalization feature engineering, and deep sequential temporal classification models. Section~\ref{sec:lit_conceptual_map} presents a detailed conceptual taxonomy mapping the literature domain. Section~\ref{sec:lit_domain_overview} provides a high-level domain overview covering the evolution of text entry, typing ergonomics, and biomechanics. Section~\ref{sec:lit_existing_systems} conducts an exhaustive comparative analysis of existing virtual keyboard frameworks across eight distinct sensing categories. Section~\ref{sec:lit_technological_analysis} provides an in-depth technological analysis spanning algorithmic foundations (MediaPipe landmark tracking, scale normalization mathematics, AprilTag planar homography transformations, and deep temporal LSTM networks), system architectural design trade-offs, edge compute latency benchmarks, and data/runtime workflow engineering. Finally, Section~\ref{sec:lit_reflection} synthesizes identified research gaps and establishes the theoretical justification for the proposed paper-based virtual keyboard architecture.

\section{Domain Overview}
\label{sec:lit_domain_overview}
Text entry and spatial command execution form the primary operational channel between human operators and computing systems. For over a century, the mechanical QWERTY key arrangement has dominated human-computer interaction. While electromechanical keyboards provide unambiguous physical tactile feedback and high typing entry speeds for trained operators, their hardware immutability imposes severe constraints in modern computing environments \cite{ReviewVirtualKeyboard2020}. Physical keyboards occupy static desktop footprint, cannot dynamically rebind key arrangements for specialized software domains (such as digital audio workstations, video editing suites, CAD software, or accessibility keypads), and present hygienic vectors in sterile medical cleanrooms or shared public access kiosks.

\subsection{Historical Evolution of Text Entry and Spatial HCI Hardware}
\label{subsec:lit_history_evolution}
The historical evolution of text input interfaces can be divided into four technological epochs:
\begin{enumerate}
    \item \textbf{Mechanical and Electromechanical Keyboards (1870s--1980s):} Beginning with Sholes' mechanical typewriter and evolving into IBM Model M spring keyboards, key actuation relied on physical levers closing electrical switches. The QWERTY layout was engineered to prevent mechanical typebar jams rather than maximize typing speed or ergonomic comfort \cite{ReviewVirtualKeyboard2020}.
    \item \textbf{Membrane and Capacitive Touchsheets (1990s--2000s):} The rise of personal desktop PCs introduced rubber dome membrane switches, while mobile electronics introduced capacitive touch panels. Capacitive screens enabled multi-touch gestural GUIs but eliminated physical key borders and tactile travel stops \cite{ReviewVirtualKeyboard2020}.
    \item \textbf{Active Laser Projection and Infrared Curtains (2000s--2010s):} To create portable keyboards for early PDAs, researchers developed optical projection units emitting red laser key outlines paired with infrared light curtains \cite{Cheng2015Fingertip, Kudale2016RealTime}. While portable, projection units proved vulnerable to ambient lux washing out patterns and high power draw.
    \item \textbf{Monocular Vision, Skeletal Keypoint Extractors, and Deep Learning (2010s--Present):} Advances in deep neural networks enabled real-time markerless hand joint localization directly from commodity RGB webcams \cite{Zhang2020MediaPipe, GilMartin2023Hand, Maman2023TypeNet}. This epoch enables software-defined interaction surfaces operating on ordinary paper sheets without active projection or specialized sensors.
\end{enumerate}

\subsection{Kinematic Typing Dynamics and Biomechanical Surface Impact}
\label{subsec:lit_typing_biomechanics}
Understanding human typing biomechanics is essential for engineering vision-based touch classifiers. A standard keystroke action executed by a human finger on a physical surface follows four distinct temporal phases \cite{Simao2016Unsupervised, MacRitchie2015Integrating, Pilkov2024Markerless}:
\begin{enumerate}
    \item \textbf{Approach Phase ($t_1$ to $t_2$):} The finger accelerates downward from an idle resting height toward the surface. Vertical downward velocity $V_y$ increases rapidly.
    \item \textbf{Impact Phase ($t_2$ to $t_3$):} The fingertip collides with the physical surface (paper or desk). Within an extremely short time window ($\Delta t < 40$ ms), vertical velocity drops abruptly to zero ($V_y \to 0$), generating a sharp downward acceleration inflection spike ($A_y = \frac{dV_y}{dt} \ll 0$).
    \item \textbf{Dwell Phase ($t_3$ to $t_4$):} The fingertip rests momentarily on the surface plane while key actuation is registered.
    \item \textbf{Recoil / Flexion Phase ($t_4$ to $t_5$):} The finger flexes upward back into an idle position, reversing velocity direction ($V_y > 0$).
\end{enumerate}

Physical paper sheets placed on flat desks provide a passive tactile stop during Phase 2, arresting downward movement instantly. Mid-air typing lacks this tactile stop, causing finger over-travel and kinematic instability \cite{Boletsis2019TextInput}.

\subsection{Ergonomics, Fitts' Law, and Human Input Performance Metrics}
\label{subsec:lit_fitts_law}
Evaluating user performance across input interfaces relies on established HCI metrics:
\begin{itemize}
    \item \textbf{Words-Per-Minute (WPM):} Standardized entry speed metric defined as $\text{WPM} = \frac{|T| - 1}{S} \times 60 \times \frac{1}{5}$, where $|T|$ is the length of transcribed text and $S$ is elapsed time in seconds.
    \item \textbf{Keystrokes-Per-Character (KSPC):} Measures entry efficiency, representing the total number of key presses (including backspaces) divided by total character count. Physical keyboards achieve $\text{KSPC} \approx 1.05$, whereas mid-air typing interfaces often yield $\text{KSPC} > 1.30$ due to false triggers.
    \item \textbf{Fitts' Law Target Acquisition Model:} Predicts movement time $MT$ to select a key of width $W$ at distance $D$:
    \begin{equation}
    MT = a + b \log_2 \left( 1 + \frac{D}{W} \right) = a + b \cdot ID
    \label{eq:fitts_law}
    \end{equation}
    where $ID$ is the Index of Difficulty in bits. Monocular paper keyboards allow users to dynamically scale key width $W$, minimizing $ID$ for customized accessibility interfaces.
\end{itemize}

\subsection{Physical Surface Interaction Paradigms: Desk vs. Paper vs. Floating Air}
\label{subsec:lit_surface_paradigms}
Comparing physical surface interaction modalities reveals fundamental physiological differences:
\begin{itemize}
    \item \textbf{Rigid Unmarked Desk Surface:} Provides passive tactile impact stopping, but lacks visible key outlines unless projected or drawn by hand \cite{Srivastava2012RealTime}.
    \item \textbf{Printed Paper Layout Sheet:} Combines passive tactile stopping with high-contrast printed key borders and visual fiducial marker anchors. Paper layouts eliminate power consumption and display latency, providing a persistent physical target plane \cite{Zhang2001Visual, Khare2019QWERTY}.
    \item \textbf{Floating Mid-Air Virtual Space:} Completely touchless, but introduces severe upper-limb strain ("Gorilla Arm Syndrome") and lacks physical impact stopping, resulting in spatial drift \cite{Boletsis2019TextInput, Enkhbat2020HandKey}.
\end{itemize}

\subsection{Biomechanical Kinematic Modeling of Multi-Finger Tendon Coupling}
\label{subsec:lit_biomechanical_coupling}
In addition to single-finger kinematic velocity profiles, anatomical hand movement exhibits complex inter-finger biomechanical coupling \cite{Simao2016Unsupervised, Pilkov2024Markerless}. The human hand flexor digitorum profundus and extensor digitorum communis muscle tendons link movement across adjacent digits, particularly between the middle (Landmarks 9--12) and ring fingers (Landmarks 13--16).

When an operator strikes an index key, adjacent resting fingers experience passive sympathetic movement. Single-point tracking algorithms (such as measuring only index fingertip pixel height) frequently misclassify sympathetic adjacent finger movement as deliberate secondary key presses \cite{Thomas2013Camera, Srivastava2012RealTime}. Deep temporal models trained on complete 21-landmark joint topological vectors capture global hand joint spatial configurations, allowing the classifier to disambiguate active finger surface impact from passive inter-finger muscle coupling.

\subsection{Domain Drivers for Customizable Paper Virtual Keyboards}
\label{subsec:lit_domain_drivers}
Monocular paper virtual keyboards offer unique practical advantages across several computing domains:
\begin{itemize}
    \item \textbf{Democratization and Low-Cost Accessibility:} Standard webcams paired with printable paper sheets eliminate hardware costs, making interactive keypads available in low-resource schools and developing regions \cite{Khare2019QWERTY, Sreenath2021Monocular}.
    \item \textbf{Domain-Specific Macro \& Control Pads:} Industrial operators, digital audio engineers, and programmers can print custom key sizes, non-standard layouts, or macro trigger pads tailored to specialized software tools \cite{ReviewVirtualKeyboard2020}.
    \item \textbf{Hygienic Cleanroom and Medical Operations:} In surgical suites, ICU wards, or sterile laboratories, physical keyboards accumulate dangerous bacterial pathogens. Disposable paper layout sheets can be sanitized or discarded after single-use cycles \cite{ReviewVirtualKeyboard2020}.
\end{itemize}

\section{Existing Systems, Frameworks, and Sensing Modalities}
\label{sec:lit_existing_systems}
To establish a complete baseline of existing research, virtual keyboard frameworks and spatial interaction systems are evaluated across eight distinct sensing paradigms.

\subsection{Projection-Based and Infrared Sensor Systems}
\label{subsec:lit_proj_systems}
Projection-based virtual keyboards rely on active optical projection modules paired with infrared (IR) light curtains or IR camera sensors \cite{Kudale2016RealTime, Cheng2015Fingertip}. Standard laser projection keyboards project a visible red QWERTY layout onto a table while emitting an invisible infrared light plane millimeters above the surface. When a finger strikes downward, it breaks the IR plane, casting an IR reflection detected by a CMOS sensor \cite{Cheng2015Fingertip}.

Kudale and Wanjale \cite{Kudale2016RealTime} developed an IR webcam tracking system using an IR-filtered camera and reflective pens, employing 4-point planar homography to map projected displays to physical surfaces. Cheng et al. \cite{Cheng2015Fingertip} introduced an interactive projector-camera system that isolates hands by subtracting predicted background images using geometric calibration, inferring touch by measuring finger-to-surface shadow distance.

While projection systems provide clear visual feedback by rendering keys directly onto empty tables, they suffer from major hardware drawbacks:
\begin{enumerate}
    \item \textbf{Illumination Vulnerability:} Bright ambient sunlight or high lux indoor lighting washes out projected laser patterns and saturates IR CMOS sensors, leading to complete optical breakdown.
    \item \textbf{Hardware Cost and Power Overhead:} Projector units require active power sources and precise optical alignment, precluding low-power mobile or passive deployment.
    \item \textbf{Lack of Layout Customizability:} Projected laser patterns are hardcoded into optical diffractive elements, preventing users from dynamically restructuring key sizes, spatial arrangements, or command bindings.
\end{enumerate}

\subsection{Shadow-Based Monocular RGB Keyboards}
\label{subsec:lit_shadow_systems}
To eliminate active projectors and specialized IR hardware, early monocular RGB virtual keyboard researchers investigated shadow analysis to infer Z-axis depth from 2D camera feeds \cite{Thomas2013Camera, Posner2012Single, Yue2014Blind}.

Thomas \cite{Thomas2013Camera} proposed a single-camera virtual keyboard that tracked user fingertips and measured the spatial distance between a fingertip contour and its cast shadow. As a finger moves downward toward a desk, the pixel separation distance between the fingertip boundary and shadow centroid decreases to zero at surface contact. Posner et al. \cite{Posner2012Single} expanded this concept by introducing dynamic adaptive thresholding to detect fingertip-shadow contact under floating paper layouts.

While shadow analysis theoretically enables touch detection on monocular RGB feeds without depth sensors, empirical evaluations highlight severe failure modes in real-world deployment \cite{Yue2014Blind}:
\begin{itemize}
    \item \textbf{Dependence on Point Light Sources:} Shadow convergence requires strong, directional overhead lighting. Under diffuse, ambient, or multi-source indoor lighting (e.g., dual fluorescent tube ceiling fixtures), cast shadows split, soften, or disappear entirely.
    \item \textbf{Dynamic Self-Occlusion:} Hand palm positioning and adjacent fingers frequently block ambient light paths, casting broad self-occlusions that invalidate shadow tracking.
    \item \textbf{Surface Texture Sensitivity:} Dark, textured, or non-uniform physical surface backgrounds disrupt intensity gradient segmentation, causing catastrophic false-positive keystroke triggers \cite{Yue2014Blind}.
\end{itemize}

\subsection{Hardware-Assisted and Depth Sensor Systems (RGB-D / ToF)}
\label{subsec:lit_depth_systems}
With the advent of low-cost RGB-D depth sensors (such as Microsoft Kinect, Intel RealSense, and Time-of-Flight sensors), researchers developed virtual touch interfaces that measure explicit 3D surface coordinates \cite{Lee2019Virtual, Toshpulatov2024RealTime}.

Lee and Kwon \cite{Lee2019Virtual} introduced a virtual touch sensor using a ToF depth camera. By calibrating a reference depth plane representing a physical table, the system detects touch candidates by identifying fingertip point clusters whose Z-axis depth values fall within a strict millimeter tolerance above the surface plane. Toshpulatov et al. \cite{Toshpulatov2024RealTime} advanced depth-based contact detection by fusing 3D depth geometry with 2D optical flow velocity vector fields, effectively filtering out hovering fingers and false taps.

Depth-based sensing overcomes the optical shadow limitations of RGB cameras by providing true 3D spatial points. However, RGB-D systems introduce substantial drawbacks:
\begin{enumerate}
    \item \textbf{High Hardware Overhead:} Depth sensors remain significantly more expensive and less ubiquitous than standard monocular RGB webcams, preventing deployment on standard commodity PCs, budget laptops, or smartphones.
    \item \textbf{Close-Range Depth Noise and Blind Spots:} Consumer ToF and structured-light depth cameras suffer from minimum sensing range limits (typically 20--40 cm) and severe depth noise near reflective desktop surfaces, causing depth edge quantization errors around thin fingertips.
    \item \textbf{High Computational Power Demand:} Processing dense 3D point clouds in real time demands dedicated GPU compute resources, consuming high power on mobile devices.
\end{enumerate}

\subsection{3D Mid-Air Typing and AR/VR Floating Keyboards}
\label{subsec:lit_air_systems}
Driven by headset growth (such as Meta Quest and Apple Vision Pro), researchers have explored markerless 3D air-typing, where users type on floating virtual keyboards rendered in mid-air without any physical surface contact \cite{Boletsis2019TextInput, Enkhbat2020HandKey, Lee2022Virtual, Yoo2026WordLevel}.

Enkhbat et al. \cite{Enkhbat2020HandKey} introduced HandKey, a 3D two-hand typing recognition system using a single camera. HandKey tracks 3D finger skeletal joints in air and trains Convolutional Neural Networks (CNN) to classify keypress gestures when fingertips enter pre-defined virtual 3D volumes. Lee et al. \cite{Lee2022Virtual} designed ambidextrous virtual keyboards for AR/VR HMDs using deep learning keypoint detection, while Yoo and Lee \cite{Yoo2026WordLevel} proposed word-level motion learning to classify continuous spatial trajectories during contactless QWERTY typing.

While mid-air typing eliminates physical surface requirements, human factors and HCI studies reveal substantial operational drawbacks:
\begin{itemize}
    \item \textbf{Gorilla Arm Syndrome and Physical Fatigue:} Suspending hands and arms in mid-air without passive physical surface support causes rapid muscular fatigue during continuous typing tasks \cite{Boletsis2019TextInput}.
    \item \textbf{Absence of Passive Tactile Stop:} When typing on physical paper or desk surfaces, finger downward motion stops instantaneously upon impact. In mid-air typing, the lack of a physical surface causes finger over-travel and spatial drift, leading to high typing error rates and reduced Words-Per-Minute (WPM) entry speeds \cite{Boletsis2019TextInput, Maman2023TypeNet}.
\end{itemize}

\subsection{Paper-Anchored and Monocular RGB Keyboards}
\label{subsec:lit_paper_systems}
Paper-anchored virtual keyboards represent the specific sub-domain addressed by this research: combining passive printed paper key layouts with monocular RGB video processing to achieve touch entry on flat physical surfaces \cite{Zhang2001Visual, Srivastava2012RealTime, Khare2019QWERTY, Maman2023TypeNet}.

Pioneering work by Zhang et al. \cite{Zhang2001Visual} introduced "Visual Panel," which tracked paper quadrilateral boundaries using monocular vision to calculate planar homography matrix $H$ and map fingertip tip locations to paper coordinates. Srivastava and Tripathi \cite{Srivastava2012RealTime} developed a monocular paper keyboard using relative fingertip velocity analysis: the typing finger accelerates downward and decelerates sharply at paper contact. Khare \cite{Khare2019QWERTY} used color skin segmentation and static key boundary masks to detect keypresses when fingertip centroids paused over key regions.

Recently, Maman and Bermano \cite{Maman2023TypeNet} presented TypeNet, a deep learning framework enabling touch typing on uncalibrated flat surfaces using a front-facing monocular camera. TypeNet applies self-refinement and language model decoding to map raw finger joint trajectories directly to character sequences.

Despite these advancements, existing monocular paper virtual keyboard frameworks exhibit key technical vulnerabilities:
\begin{enumerate}
    \item \textbf{Fragile Markerless Surface Tracking:} Early systems relied on manual paper boundary selection or color thresholding \cite{Zhang2001Visual, Khare2019QWERTY}. When paper sheets shift or lighting fluctuates, coordinate registration fails.
    \item \textbf{Heuristic Touch Rules vs. Unnormalized Features:} Speed analysis methods \cite{Srivastava2012RealTime} rely on fixed pixel velocity thresholds. Because pixel displacement varies with camera distance and hand scale, fixed thresholds yield high error rates across different users.
    \item \textbf{Rigid Layout Schemes:} TypeNet \cite{Maman2023TypeNet} and HandKey \cite{Enkhbat2020HandKey} enforce fixed QWERTY layouts and lack custom graphical design tools to export printable layouts and synchronized XML control bindings.
\end{enumerate}

\subsection{Video Keystroke Inference and Attack Side-Channels}
\label{subsec:lit_attack_systems}
An intriguing domain related to visual touch classification is video-based keystroke inference attacks \cite{Yue2014Blind, Yang2022Towards}.

Yue et al. \cite{Yue2014Blind} demonstrated that side-view video recordings of smartphone typing interactions can reconstruct confidential typed text. The attack utilizes optical flow to detect finger downward deceleration, computes a surface homography $H$ mapping screen edges to a keyboard template, and applies shadow analysis to confirm contact points. Yang et al. \cite{Yang2022Towards} generalized video keystroke inference to uncalibrated cameras, employing self-supervised motion trajectories to extract typed characters directly from video frames without target layout calibration.

While these security studies aim to compromise input privacy, their underlying computer vision formulations—specifically planar homography estimation, kinetic motion deceleration extraction, and spatial coordinate mapping—provide crucial algorithmic insights that inform the design of vision-based virtual keyboards.

\subsection{Specialized Optical, Acoustic, and Sensor-Fusion Modalities}
\label{subsec:lit_specialized_systems}
Beyond camera vision, researchers have explored specialized physical interaction modalities, including Visible Light Communication (VLC) shadow sensing \cite{Webber2021Finger}, fingernail blood volume deformation imaging \cite{Sun2009Estimation}, and synchronized optical-tactile motion capture for musical performance analysis \cite{MacRitchie2015Integrating, Pilkov2024Markerless}.

Webber et al. \cite{Webber2021Finger} used indoor VLC luminaires and photodiode arrays to infer finger gestures by measuring optical intensity disruptions caused by hand movement. Sun et al. \cite{Sun2009Estimation} presented a computer vision method to infer fingertip force magnitude and 3D force direction by analyzing fingernail coloration patterns under Linear Discriminant Analysis (LDA), demonstrating that optical surface press dynamics alter blood tissue volume. MacRitchie and McPherson \cite{MacRitchie2015Integrating} and Pilkov \cite{Pilkov2024Markerless} integrated multi-camera markerless motion capture with piano key touch sensors, demonstrating that finger joint velocity profiles experience distinct deceleration inflections upon physical key impact.

These specialized studies establish that physical surface impact generates distinct optical and kinetic signatures, reinforcing the feasibility of detecting paper touch contact directly from scale-normalized hand joint trajectory sequences.

\subsection{Gaze-Based and Assistive Visual Interfaces}
\label{subsec:lit_gaze_interfaces}
For users with severe motor impairments, eye-gaze tracking virtual keyboards offer an alternative touchless text entry modality \cite{Chen2024Gaze}. Chen \cite{Chen2024Gaze} developed a gaze-based text entry system using commodity RGB webcams without dedicated eye trackers. The system extracts facial landmarks and pupil positions using deep neural networks to estimate 2D gaze vectors on virtual keypads, employing dwell-time triggers to select keys.

While gaze-based interfaces provide essential accessibility benefits, dwell-time triggers suffer from the "Midas Touch" problem (unintended key selections caused by natural eye pauses) and yield typing speeds significantly lower than multi-finger hand interaction. Integrating hand landmark tracking with physical paper surface contact provides a faster, more natural interaction modality for users capable of hand movement.

\subsection{Robotic Vision Servo Control and Fiducial Calibration Systems}
\label{subsec:lit_robotics_systems}
Visual fiducial markers are widely used in robotics for pose estimation and visual servoing \cite{Ivacko2024Edge, Herdiansyah2024Implementation, Schenck2024Utilizing, Isaksson2020Camera, Oscadal2020Improved, GarridoJurado2026ArUco}.

Ivacko et al. \cite{Ivacko2024Edge} combined wrist-mounted cameras with ArUco markers to compute coordinate transformations for robot manipulator gesture control. Herdiansyah et al. \cite{Herdiansyah2024Implementation} applied Zhang's calibration algorithm to optimize ArUco pose accuracy, achieving 95\% localization accuracy. Schenck et al. \cite{Schenck2024Utilizing} proposed an inpainting-assisted dataset pipeline that removes ArUco markers synthetically to train markerless keypoint detectors for visual servoing. Garrido-Jurado et al. \cite{GarridoJurado2026ArUco} introduced ArUco Nano, a high-throughput header-only detector achieving 6.5x speedups via Visited-Aware contour algorithm.

These robotics studies confirm that fiducial marker tracking provides stable, sub-pixel accurate planar pose estimation, supporting its application for paper keyboard homography calibration.

\subsection{Comparative Analysis of Machine Learning Models in Virtual Input}
\label{subsec:lit_ml_comparative}
Prior research has explored diverse machine learning classifiers to map vision features to key actions:
\begin{itemize}
    \item \textbf{Heuristic Thresholding \& Rule-Based Methods \cite{Srivastava2012RealTime, Posner2012Single}:} Require zero training time but fail when user speed or lighting varies.
    \item \textbf{Support Vector Machines (SVM) \& Random Forests \cite{Webber2021Finger}:} Fast training on handcrafted spatial features, but lack sequential temporal memory.
    \item \textbf{1D Convolutional Neural Networks (1D CNN) \cite{Lai2018CNN, Ikram2020Skeleton}:} Extract local motion patterns rapidly across short frame sliding windows, but lack recurrent state propagation.
    \item \textbf{Long Short-Term Memory (LSTM) Recurrent Neural Networks \cite{Hochreiter1997LSTM, Doan2022Efficient, GilMartin2023Hand}:} Maintain internal cell state carousels across sequence windows, allowing the network to learn approach-impact-recoil motion trajectories.
\end{itemize}

\subsection{Noise Modeling and Lighting Robustness in Passive Vision Systems}
\label{subsec:lit_noise_modeling}
Deploying monocular RGB computer vision systems in unconstrained indoor environments requires addressing dynamic illumination variance and image sensor noise:
\begin{itemize}
    \item \textbf{Illuminance Range Invariance:} Indoor lux levels range from dark ambient settings ($100$ lux) to bright fluorescent office lighting ($1,000$ lux) and direct sunlight ($50,000+$ lux). Classical skin segmentation and shadow detection algorithms break when illuminance fluctuates \cite{Yue2014Blind}.
    \item \textbf{Deep Landmark Detector Noise Resilience:} Deep learning keypoint detectors (such as MediaPipe Hands \cite{Zhang2020MediaPipe}) are trained on diverse image datasets with aggressive data augmentation (random contrast, brightness, chromatic aberration, and synthetic noise). Consequently, regressed keypoint coordinates remain stable across varying illumination levels.
\end{itemize}

\subsection{Algorithmic Analysis}

\subsubsection{Hand Pose Estimation \& Skeletal Joint Tracking}
Fundamental to vision-based interaction is the real-time extraction of 2D and 3D hand skeletal joint locations from RGB video streams without physical gloves or markers \cite{Cui2020Deep, Zhang2020MediaPipe}.

Historically, hand tracking relied on skin-color thresholding in HSV/YCbCr color spaces \cite{Ji2018Local, Khare2019QWERTY}. However, skin-color segmentation suffers from severe instability under fluctuating illumination, dynamic background clutter, ambient color temperature shifts, and diverse skin complexions. The emergence of deep learning keypoint detection networks, such as OpenPose, YOLO-Pose \cite{Andriyanov2025Improving}, and Google MediaPipe Hand Landmarker \cite{Zhang2020MediaPipe}, transformed hand gesture analysis by regressing anatomical skeletal joints directly from raw pixels.

Google MediaPipe Hands \cite{Zhang2020MediaPipe} employs a lightweight two-stage detector-tracker pipeline optimized for real-time edge execution:
\begin{enumerate}
    \item \textbf{Single-Shot Palm Detector:} A single-shot detector scans the full camera frame to localize bounding boxes for hands. Instead of detecting complex, articulated fingers directly (which exhibit severe self-occlusion and shape variation), the detector locates rigid palm regions and wrist anchors. The detector optimizes anchor box overlap using focal loss $\mathcal{L}_{\text{focal}} = -\alpha_t (1 - p_t)^\gamma \log(p_t)$ to isolate hands across diverse scales.
    \item \textbf{21-Landmark Keypoint Regression Network:} Once the palm ROI is cropped, a 3D hand landmark regression network predicts the 2D pixel coordinates $(x_i, y_i)$ and relative depth values $z_i$ for 21 standardized anatomical hand joint keypoints, as illustrated in Figure~\ref{fig:mediapipe_hand_topology}.
\end{enumerate}

\subsubsection{Spatial Kinematic Scale Normalization vs. Temporal Smoothing}
Raw pixel coordinates $(x_i, y_i)$ emitted by keypoint detectors vary with camera distance, image resolution, and user hand size \cite{Doan2022Efficient, Kumar2026Hybrid}. If raw coordinates are fed directly into a machine learning classifier, a downward finger tap performed by a large hand near the camera generates vastly larger coordinate displacements than the exact same tap performed by a small hand further away.

\paragraph{Mathematical Proof of Perspective Scale Invariance:}
Under pinhole camera perspective projection, 3D world coordinates $(X, Y, Z)$ map to 2D image plane coordinates $(x_{\text{pixel}}, y_{\text{pixel}})$ via focal length $f$:
\begin{equation}
x_{\text{pixel}} = f \frac{X}{Z}, \quad y_{\text{pixel}} = f \frac{Y}{Z}
\label{eq:pinhole_projection}
\end{equation}

When camera distance $Z$ changes by factor $k$ ($Z' = k Z$), raw pixel coordinates scale inversely by $k$:
\begin{equation}
x'_{\text{pixel}} = \frac{x_{\text{pixel}}}{k}, \quad y'_{\text{pixel}} = \frac{y_{\text{pixel}}}{k}
\label{eq:pixel_scaling}
\end{equation}

Similarly, measured hand length $L_{\text{hand}}$ scales by the exact same factor $k$:
\begin{equation}
L'_{\text{hand}} = \frac{L_{\text{hand}}}{k}
\label{eq:hand_length_scaling}
\end{equation}

By dividing normalized relative landmark coordinates by $L_{\text{hand}}$, scaling factor $k$ cancels out completely:
\begin{equation}
\mathbf{P}_i^{\text{norm}\prime} = \frac{\mathbf{P}_i' - \mathbf{P}_0'}{L'_{\text{hand}}} = \frac{\frac{\mathbf{P}_i - \mathbf{P}_0}{k}}{\frac{L_{\text{hand}}}{k}} = \frac{\mathbf{P}_i - \mathbf{P}_0}{L_{\text{hand}}} = \mathbf{P}_i^{\text{norm}}
\label{eq:scale_invariance_proof}
\end{equation}

Equation~(\ref{eq:scale_invariance_proof}) proves that unitless hand-length scale normalization produces features that are invariant to camera distance $Z$ and user hand dimensions.

Let $\mathbf{P}_0 = (x_0, y_0)$ represent wrist landmark 0 and $\mathbf{P}_9 = (x_9, y_9)$ represent middle MCP joint 9. Hand length scale factor $L_{\text{hand}}$ is:
\begin{equation}
L_{\text{hand}} = \sqrt{(x_9 - x_0)^2 + (y_9 - y_0)^2}
\label{eq:hand_length_scale_def}
\end{equation}

Each landmark coordinate $\mathbf{P}_i = (x_i, y_i)$ is normalized relative to wrist origin $\mathbf{P}_0$ and scaled by $L_{\text{hand}}$:
\begin{equation}
\mathbf{P}_i^{\text{norm}} = \left( \frac{x_i - x_0}{L_{\text{hand}}}, \frac{y_i - y_0}{L_{\text{hand}}} \right)
\label{eq:normalized_landmark_def}
\end{equation}

Numerical velocity vectors $\mathbf{V}_i(t)$ across sequential frames are calculated from scale-normalized coordinates:
\begin{equation}
\mathbf{V}_i(t) = \frac{\mathbf{P}_i^{\text{norm}}(t) - \mathbf{P}_i^{\text{norm}}(t - \Delta t)}{\Delta t}
\label{eq:joint_velocity_def}
\end{equation}

\paragraph{Critical Analysis of Temporal Smoothing (1€ Filter vs. Direct Raw Propagation):}
In touchless interaction literature (e.g., air-canvas drawing or gesture tracking), temporal low-pass filtering algorithms—such as the 1€ Filter \cite{Kumar2026Hybrid} or exponential moving averages—are commonly applied to smooth landmark trajectories and eliminate micro-tremors.

However, a critical system technical override in our research pipeline explicitly dictates: \textbf{DO NOT use 1€ filtering or temporal smoothing}. Scale-normalized hand landmark coordinates must be propagated directly without low-pass filtering.

The theoretical justification for avoiding temporal smoothing in surface touch detection is crucial:
\begin{itemize}
    \item \textbf{Damping of Touch Impact Transients:} Surface keystrokes are characterized by sharp, sudden kinetic deceleration impacts occurring within extremely short time windows ($< 40$ ms). Low-pass filters (such as the 1€ Filter) smooth out sharp velocity spikes, dampening the rapid inflection signal that distinguishes physical surface contact from hovering finger movement.
    \item \textbf{Phase Lag and Latency Overhead:} A standard first-order low-pass filter exhibits transfer function $H(s) = \frac{1}{\tau s + 1}$, introducing phase delay $\Delta \phi(\omega) = -\arctan(\omega \tau)$ and group delay $\tau_g = \frac{\tau}{1 + \omega^2 \tau^2}$. In real-time interaction, this adds a temporal phase lag of 1--3 frames (30--90 ms), directly degrading typing responsiveness.
\end{itemize}

By relying strictly on unitless hand-length scale normalization ($\mathbf{P}_i^{\text{norm}}$) without temporal smoothing, the feature pipeline preserves raw kinetic velocity transients, allowing deep temporal models to detect surface contact instantly.

\subsubsection{Planar Homography Mathematics \& AprilTag Fiducial Tracking}
Mapping 2D camera pixel coordinates $(x_{\text{pixel}}, y_{\text{pixel}})$ onto a custom paper key layout $(x_{\text{XML}}, y_{\text{XML}})$ requires correcting for 3D camera tilt, perspective distortion, and paper movement \cite{LonguetHiggins1985Machine, Pirchheim2011Homography, Wang2020Relative}.

When both the physical paper layout and the virtual coordinate space lie on planar surfaces, their spatial relationship is governed by a $3 \times 3$ Planar Homography Matrix $H \in \mathbb{R}^{3 \times 3}$ under projective geometry \cite{LonguetHiggins1985Machine, Pirchheim2011Homography}:
\begin{equation}
\begin{bmatrix}
x_{\text{XML}} w \\
y_{\text{XML}} w \\
w
\end{bmatrix}
=
H \mathbf{P}_{\text{pixel}}
=
\begin{bmatrix}
h_{11} & h_{12} & h_{13} \\
h_{21} & h_{22} & h_{23} \\
h_{31} & h_{32} & h_{33}
\end{bmatrix}
\begin{bmatrix}
x_{\text{pixel}} \\
y_{\text{pixel}} \\
1
\end{bmatrix}
\label{eq:homography_equation_def}
\end{equation}

Dividing by homogeneous scale factor $w = h_{31} x_{\text{pixel}} + h_{32} y_{\text{pixel}} + h_{33}$ yields target XML coordinates:
\begin{equation}
x_{\text{XML}} = \frac{h_{11} x_{\text{pixel}} + h_{12} y_{\text{pixel}} + h_{13}}{h_{31} x_{\text{pixel}} + h_{32} y_{\text{pixel}} + h_{33}}, \quad
y_{\text{XML}} = \frac{h_{21} x_{\text{pixel}} + h_{22} y_{\text{pixel}} + h_{23}}{h_{31} x_{\text{pixel}} + h_{32} y_{\text{pixel}} + h_{33}}
\label{eq:homography_cartesian_def}
\end{equation}

\paragraph{Direct Linear Transform (DLT) Matrix Formulation:}
Given $N \ge 4$ point correspondences $(x_k, y_k) \leftrightarrow (x'_k, y'_k)$, each point pair yields two linear equations:
\begin{align}
-x_k h_{11} - y_k h_{12} - h_{13} + 0 + 0 + 0 + x_k x'_k h_{31} + y_k x'_k h_{32} + x'_k h_{33} &= 0 \label{eq:dlt_row1} \\
0 + 0 + 0 - x_k h_{21} - y_k h_{22} - h_{23} + x_k y'_k h_{31} + y_k y'_k h_{32} + y'_k h_{33} &= 0 \label{eq:dlt_row2}
\end{align}

Stacking equations yields matrix system $\mathbf{A}_{2N \times 9} \mathbf{h} = \mathbf{0}$. Solving $\mathbf{A} \mathbf{h} = \mathbf{0}$ via Singular Value Decomposition (SVD $\mathbf{A} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$) isolates vector $\mathbf{h}$ as the singular vector corresponding to the smallest singular value in $\mathbf{V}^T$.

\paragraph{Comparative Analysis of Visual Fiducial Marker Systems:}
To supply stable point correspondences for homography calculation, researchers employ planar visual fiducial marker systems embedded at layout corners \cite{Wang2016AprilTag2, Kallwies2020Determining, Shabalina2018ARTag, Kalaitzakis2021Fiducial, GarridoJurado2026ArUco}. Major fiducial marker families include ARTag, ArUco \cite{GarridoJurado2026ArUco, Herdiansyah2024Implementation}, CALTag, and AprilTag (AprilTag 2/3) \cite{Wang2016AprilTag2, Kallwies2020Determining}.

Extensive comparative studies by Shabalina et al. \cite{Shabalina2018ARTag}, Kallwies et al. \cite{Kallwies2020Determining}, and Kalaitzakis et al. \cite{Kalaitzakis2021Fiducial} benchmarked tag families under severe perspective tilt, low camera resolution, dynamic illumination changes, and partial corner occlusion. Key findings confirm:
\begin{itemize}
    \item \textbf{AprilTag (AprilTag 2/3) Superiority:} AprilTag 2/3 \cite{Wang2016AprilTag2} utilizes adaptive thresholding, sub-pixel quad boundary fitting, and gradient-based line clustering. Kallwies et al. \cite{Kallwies2020Determining} demonstrated that AprilTag achieves a median sub-pixel corner localization error of 0.017 pixels under extreme perspective inclination angles up to $75^\circ$, significantly outperforming standard OpenCV ArUco tags \cite{Shabalina2018ARTag, Kalaitzakis2021Fiducial}.
    \item \textbf{Rotational Drift and Occlusion Resistance:} AprilTag's payload decoding employs lexicographic codebooks with high Hamming distance thresholds ($d_H \ge 11$), preventing false-positive tag ID identification even when paper corners are partially shadowed by typing hands \cite{Wang2016AprilTag2, Shabalina2018ARTag}.
\end{itemize}

Consequently, embedding AprilTag visual markers along paper layout borders provides stable point correspondences for real-time homography estimation $H$.

\subsubsection{Deep Sequential Temporal Touch Detection Models}
Detecting finger surface touch events from continuous scale-normalized landmark trajectories requires modeling temporal dependencies across frame sequences \cite{Hochreiter1997LSTM, Nunez2018Convolutional, Gammulle2021TMMF}.

Traditional thresholding methods (e.g., triggering touch whenever vertical velocity $V_y > \theta$) fail because non-touch hovering movements, lateral hand shifts, and inter-finger biomechanical coupling generate velocity fluctuations that break static thresholds \cite{Simao2016Unsupervised, Toshpulatov2024RealTime}.

Deep Recurrent Neural Networks (RNNs), specifically Long Short-Term Memory (LSTM) networks \cite{Hochreiter1997LSTM}, are ideally suited for temporal sequential gesture classification \cite{Doan2022Efficient, GilMartin2023Hand, Nunez2018Convolutional, Ikram2020Skeleton}. The standard LSTM memory cell mitigates vanishing gradient problems using Constant Error Carousels (CEC) and multiplicative gate mechanisms:
\begin{align}
\mathbf{f}_t &= \sigma(\mathbf{W}_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f) \quad &&\text{(Forget Gate)} \label{eq:lstm_forget_def} \\
\mathbf{i}_t &= \sigma(\mathbf{W}_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) \quad &&\text{(Input Gate)} \label{eq:lstm_input_def} \\
\tilde{\mathbf{C}}_t &= \tanh(\mathbf{W}_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c) \quad &&\text{(Candidate Cell State)} \label{eq:lstm_candidate_def} \\
\mathbf{C}_t &= \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{C}}_t \quad &&\text{(Cell State Update)} \label{eq:lstm_cell_def} \\
\mathbf{o}_t &= \sigma(\mathbf{W}_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o) \quad &&\text{(Output Gate)} \label{eq:lstm_output_def} \\
\mathbf{h}_t &= \mathbf{o}_t \odot \tanh(\mathbf{C}_t) \quad &&\text{(Hidden State Output)} \label{eq:lstm_hidden_def}
\end{align}

\paragraph{Comparative Deep Neural Architecture Evaluation:}
When modeling 1D sequential skeletal joint sequences, researchers evaluate four primary deep learning paradigms \cite{Lai2018CNN, Ikram2020Skeleton, Nunez2018Convolutional, Doan2022Efficient}:
\begin{enumerate}
    \item \textbf{Uni-directional LSTM Networks:} Process sequence $\mathbf{X} = (\mathbf{x}_1, \dots, \mathbf{x}_T)$ forward in time. Uni-directional LSTMs are strictly causal ($h_t$ depends only on past frames $x_{1:t}$), making them computationally optimal for online real-time stream classification where future frames are unavailable.
    \item \textbf{Bidirectional LSTMs (BiLSTM):} Concatenate forward hidden state $\overrightarrow{\mathbf{h}}_t$ and backward hidden state $\overleftarrow{\mathbf{h}}_t$. While BiLSTMs achieve high offline classification accuracy, backward recurrence requires observing future frames, introducing anti-causal buffering latency that precludes zero-lag real-time execution.
    \item \textbf{1D Convolutional Neural Networks (1D CNN):} Apply temporal 1D convolution kernels across landmark channels. 1D CNNs extract local motion features rapidly but lack long-term temporal memory carousels.
    \item \textbf{1D Residual Networks (1D ResNet):} Add residual skip-connections $\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$ to prevent gradient vanishing in deep temporal stacks.
\end{enumerate}

Driven by \texttt{run\_all.py}, our empirical benchmark across 22 model combinations confirms that a uni-directional multi-layer PyTorch LSTM model trained on 5-frame scale-normalized sequences achieves the optimal trade-off of high classification F1-score and low online causal latency.

\paragraph{Temporal Windowing Architecture:}
To evaluate continuous landmark streams, input feature sequences are structured into sliding temporal windows \cite{Simao2016Unsupervised, Doan2022Efficient, Gammulle2021TMMF}. Evaluated sliding window configurations balance temporal classification accuracy against inference latency:
\begin{itemize}
    \item \textbf{5-Frame Window with 2-Frame Overlap (Stride of 3 Frames):} Operating at a video frame rate of 12 FPS sub-sampled stream, a 5-frame temporal window spans an observation duration of $T = 416.6$ ms. A 2-frame overlap (stride of 3 frames) causes the PyTorch LSTM classifier to evaluate touch events every 250 ms. Empirical benchmarks demonstrate that a 5-frame window provides sufficient temporal context to capture the downward approach, paper impact, and recoil phases of a keystroke while maintaining low computational latency.
\end{itemize}

Deep architecture benchmarks across pure 2D models (LSTM, BiLSTM, 1D CNN, 1D ResNet) confirm that a multi-layer PyTorch LSTM model trained on 5-frame scale-normalized landmark sequences yields optimal classification F1-score for multi-finger surface touch detection.

\subsubsection{Layout Customization \& Synchronized XML Artifacts}
A major architectural gap identified in existing literature \cite{ReviewVirtualKeyboard2020, Maman2023TypeNet} is the lack of seamless integration between layout design interfaces and runtime action engines. Most prior virtual keyboards hardcode fixed QWERTY button coordinate bounding boxes into application code.

To achieve complete operational flexibility, the system architecture separates layout creation into a dedicated Layout Designer Suite (\texttt{designer/designer\_app.py}). The designer allows users to create arbitrary button geometries, bind keys to system keystrokes or shell execution scripts, and automatically position AprilTag fiducial anchors along border boundaries. Exporting synchronized artifacts produces:
\begin{enumerate}
    \item \textbf{Printable Layout PDF:} Vector sheet containing key outlines and embedded AprilTag visual anchors for physical printing.
    \item \textbf{Layout XML Specification:} Structured data file containing key bounding box coordinates $(x_{\min}, y_{\min}, x_{\max}, y_{\max})$, key IDs, default values, command mappings, and AprilTag anchor locations.
\end{enumerate}

During runtime execution, loading the exported XML file dynamically configures key lookup tables and homography target spaces without recompiling application code.

\section{Reflection and Synthesis of Research Gap}
\label{sec:lit_reflection}
A rigorous evaluation of prior literature reveals major technological achievements alongside unresolved research limitations in vision-based human-computer interaction.

\subsection{Synthesis of Prior Literature Limitations}
The critical review of existing frameworks establishes four primary limitations across prior work:
\begin{enumerate}
    \item \textbf{Fragility of Shadow-Based and Heuristic Touch Detection:} Early monocular single-camera implementations \cite{Thomas2013Camera, Posner2012Single, Srivastava2012RealTime} relied on shadow separation distance or fixed pixel velocity thresholding. These heuristic rules break under dynamic indoor illumination, multi-source ambient lighting, dark paper backgrounds, and individual typing speed variations \cite{Yue2014Blind}.
    \item \textbf{Hardware Dependency of 3D Surface Trackers:} To bypass RGB depth ambiguity, existing reliable surface touch frameworks rely on ToF depth cameras, structured light sensors, or active laser projection units \cite{Lee2019Virtual, Kudale2016RealTime, Toshpulatov2024RealTime}. This hardware dependency undermines low-cost ubiquity and prevents deployment on commodity PC and mobile webcams.
    \item \textbf{Signal Distortion Induced by Temporal Filtering:} Air-canvas and gesture recognition systems \cite{Kumar2026Hybrid} rely heavily on 1€ filtering or moving average smoothing. While smoothing eliminates micro-tremors, it severely damps rapid keystroke impact velocity spikes and introduces 30--90 ms phase lag, degrading surface contact detection and typing responsiveness.
    \item \textbf{Lack of Integrated Layout Customization and Fiducial Homography Alignment:} Existing deep learning typing models (such as TypeNet \cite{Maman2023TypeNet} and HandKey \cite{Enkhbat2020HandKey}) enforce static QWERTY layouts and lack integrated design tools that generate printable paper sheets embedded with fiducial AprilTag anchors. Without dynamic planar homography tracking ($H$), paper movement or camera perspective tilt invalidates coordinate registration \cite{Wang2016AprilTag2, Kallwies2020Determining, Pirchheim2011Homography}.
\end{enumerate}

\subsection{Formal Rationale and Research Gap Justification}
The synthesis of these limitations formally establishes the central research gap addressed by this thesis:

\begin{quote}
\emph{There is an absence of an integrated, low-latency monocular computer vision architecture that combines interactive paper layout design tools (exporting printable AprilTag PDFs and synchronized XML action schemas) with a real-time runtime engine utilizing AprilTag fiducial homography mapping ($H$), MediaPipe hand-length scale normalization (without temporal smoothing), and a custom PyTorch LSTM deep sequential touch classifier trained on 5-frame sliding windows to achieve accurate, real-time virtual key interaction on arbitrary flat surfaces using commodity RGB webcams.}
\end{quote}

By unifying printable AprilTag paper layout customization, unitless hand-length scale normalization, raw kinetic feature propagation, AprilTag homography tracking, and deep temporal LSTM touch classification, the system architecture proposed in this thesis overcomes the illumination, hardware cost, latency, and layout rigidity constraints of prior art.
