\chapter*{Appendix B: Application 1: Paper Layout Designer Suite}
\label{ch:appendix_layout_designer}

\section*{B.1 Overview of the Designer Application}
\label{sec:appendix_designer_overview}
The following screenshots illustrate Application~1 (\texttt{virtualKeyboardSetup/}\linebreak[1]\texttt{designer/main.py}), which is a layout designer developed using PySide6 (developed from the initial exploratory prototype in \texttt{designer/}). The user can create a new customized keyboard layout for macro keys by moving and resizing buttons as well as exporting the layout as an XML coordinate file and as a PDF document.

The start page of the application is illustrated in Figure~\ref{fig:appendix_designer_start} below where the user can initiate the creation of a new project, load the existing layout, or choose the pre-designed template for various shortcut purposes.

\begin{figure}[htbp]
\centering
\includegraphics[width=0.88\textwidth]{figures/layout_designer_starting_screen.png}
\caption{Application~1 startup window for project selection and template management.}
\label{fig:appendix_designer_start}
\end{figure}

\section*{B.2 Interactive 2D Design Canvas and Property Inspector}
\label{sec:appendix_designer_canvas}
Figure~\ref{fig:appendix_designer_main} displays the main design screen. The canvas displays an A4 sheet of paper in millimeters. It is easy for users to drag and drop buttons and modify their size and position on the grid. The four AprilTags always remain at the corners automatically. The side pane allows users to modify the name, label, and size of the key, while warning if keys overlap or get too close to the markers.

\begin{figure}[htbp]
\centering
\includegraphics[width=0.92\textwidth]{figures/layout_designer_main_screen.png}
\caption{Application~1 interactive 2D design canvas with key layout tools, metric grid, property inspector, and AprilTag fiducial anchors.}

\end{figure}
